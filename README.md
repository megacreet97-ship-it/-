# StreetLog — личный дневник тренировок и подготовка к МС по стритлифтингу

iOS-приложение на SwiftUI + SwiftData + Swift Charts. Работает полностью офлайн, данные хранятся только на iPhone.

## Возможности

Тёмная тема, градиентный акцент, скруглённый шрифт, кольца прогресса и крупные элементы управления, которыми удобно пользоваться прямо на тренировке.

**Дневник (ежедневный лог)**
- Прокручиваемая лента дней с отметками тренировочных дней и кнопкой «Сегодня».
- Итог дня крупно: повторения, подходы, упражнения.
- «Быстро добавить»: недавние упражнения одной кнопкой, последние значения подставляются сами.
- Окно записи: выбор упражнения с поиском, крупные степперы «Подходы / Повторения / Отягощение», быстрые кнопки веса (−2,5 / +1,25 / +2,5 / +5), подсказка «В прошлый раз», итог и тоннаж, расчётный максимум на 1 раз.
- Кнопка «+ подход» на каждой записи, редактирование по нажатию, дублирование и удаление долгим нажатием.
- «Повторить тренировку от …» — копирует прошлую тренировку на выбранный день.
- Справочник упражнений (стритлифтинг, турник, брусья, подсобка, кор) и свои упражнения.

**Мастер спорта (стритлифтинг)**
- Кольцо прогресса суммы двоеборья к выбранному нормативу, выполненное звание (КМС/МС/МСМК).
- Плитки по подтягиваниям и брусьям: рекорд, цель, отношение к весу тела.
- Нормативы по весовым категориям **до 67,5 кг и до 75 кг** для **ISF-Россия** и **WSF**: сколько осталось до КМС, МС и МСМК в каждой категории, подсказка по сгонке веса.
- Полная таблица нормативов: подтягивания, брусья, сумма.
- График динамики: рекорды, расчётные максимумы из дневника, тренд, линия цели.
- Прогноз: прирост в кг/неделю, дата выхода на цель, нужный темп до старта, статус «успеваете / отстаёте».
- Фаза подготовки по дате старта с рекомендациями, план трёх подходов на помосте, памятка по правилам.

**Аналитика**
- Периоды: 4 недели / 12 недель / год / всё время.
- Тренировки в неделю, серии дней подряд, повторения и подходы.
- Повторения и тоннаж в соревновательных движениях по неделям, рейтинг упражнений и детальный экран по каждому.

**Профиль**
- Вес тела и подсказка, в какую категорию вы проходите.
- Цель: федерация (ISF-Россия / WSF), весовая категория (67,5 / 75 / своя), звание (КМС / МС / МСМК). Норматив подставляется автоматически.
- Дата и название соревнований, экспорт дневника и попыток в CSV.

### Нормативы в приложении (мужчины, классика, отягощение в кг)

| Федерация | Категория | КМС (сумма) | МС (сумма) | МСМК (сумма) | МС подтягивания | МС брусья |
|---|---|---|---|---|---|---|
| ISF-Россия | до 67,5 | 135 | 152,5 | 180 | 67,5 | 100 |
| ISF-Россия | до 75 | 145 | 165 | 190 | 72,5 | 105 |
| WSF | до 67,5 | 122,5 | 140 | 170 | 62,5 | 90 |
| WSF | до 75 | 132,5 | 152,5 | 180 | 67,5 | 95 |

Источники: нормативы ISF-Россия, действующие с 01.01.2025 ([streetlifting.ru](https://streetlifting.ru/docs/standards/streetlifting-classic)); нормативы WSF 2025 для дивизиона с допинг-контролем (по таблице региональной федерации WSF, [frs24.ru](http://frs24.ru/st/stritlifting-normativ/)). Стритлифтинг не входит в ЕВСК, звания присваивают федерации. В двоеборье звание даётся по сумме; колонки по отдельным движениям относятся к отдельным дисциплинам. Перед стартом сверьтесь с положением турнира.

```
│   ├── Logic/

│   ├── Views/
│   │   ├── Components.swift             # дизайн-система: тема, карточки, кольца, степперы, чипы
│   │   ├── Diary/DiaryView.swift        # дневник: лента дней, итог, быстрые кнопки, записи
│   │   ├── Diary/QuickLogSheet.swift    # окно записи, выбор упражнения, новое упражнение
│   │   ├── Master/MasterView.swift      # дашборд МС: кольцо, весовые, график, прогноз, подходы
│   │   ├── Master/StandardsView.swift   # таблица нормативов
│   │   ├── Master/AttemptViews.swift    # ввод попытки на 1 раз, список попыток
│   │   ├── Analytics/AnalyticsView.swift
│   │   └── Profile/ProfileView.swift    # профиль, цель, упражнения, экспорт CSV
│   └── Assets.xcassets/                 # иконка и цвет акцента
├── Tests/StreetLogLogicTests/           # unit-тесты логики (swift test)
├── Package.swift                        # SwiftPM-пакет только для тестов логики (macOS/Linux)
├── project.yml                          # запасной вариант для Xcode 15 через XcodeGen
└── .github/workflows/ci.yml             # CI: тесты логики, сборка, запуск в симуляторе и скриншоты
```

Требования: Xcode 16 или новее, iOS 17+.

Тесты логики: `swift test` в корне репозитория.

## Как установить на свой iPhone без App Store

Понадобится Mac, iPhone с iOS 17 или новее, USB-кабель и обычный (бесплатный) Apple ID.

### 1. Установите Xcode
1. На Mac откройте App Store, найдите **Xcode** и установите (около 10+ ГБ).
2. Запустите Xcode, примите лицензию и дождитесь установки компонентов.
3. Если Xcode попросит скачать платформу iOS, согласитесь (или **Xcode → Settings → Components → iOS → Get**).

### 2. Скачайте проект
- Через терминал: `git clone https://github.com/megacreet97-ship-it/-.git StreetLog`
- Или на GitHub: **Code → Download ZIP** и распакуйте архив.

Откройте файл **`StreetLog.xcodeproj`** двойным щелчком.

### 3. Добавьте Apple ID в Xcode
**Xcode → Settings… → Accounts → «+» → Apple ID** → войдите своим Apple ID. Появится команда «Ваше Имя (Personal Team)».

### 4. Настройте подпись
1. В левой панели нажмите на синий значок проекта **StreetLog** → в списке TARGETS выберите **StreetLog** → вкладка **Signing & Capabilities**.
2. Отметьте **Automatically manage signing**.
3. **Team** → выберите «Ваше Имя (Personal Team)».
4. **Bundle Identifier** → замените `com.yourname.streetlog` на уникальный, например `com.ivanpetrov.streetlog`. Иначе Xcode напишет, что идентификатор уже занят.

### 5. Подключите iPhone
1. Подключите iPhone к Mac кабелем и разблокируйте его.
2. На iPhone появится «Доверять этому компьютеру?» → **Доверять** → введите код-пароль.

### 6. Включите режим разработчика (Developer Mode) на iPhone
1. **Настройки → Конфиденциальность и безопасность → Режим разработчика** (в самом низу экрана).
   Пункт появляется после того, как iPhone один раз подключили к Mac с открытым Xcode. Если его нет, выберите iPhone в Xcode (шаг 7) и нажмите Run: после этого пункт появится.
2. Включите переключатель → **Перезагрузить**.
3. После перезагрузки разблокируйте телефон и в появившемся окне нажмите **Включить**, затем введите код-пароль.

### 7. Соберите и запустите
1. В верхней панели Xcode, рядом с названием схемы **StreetLog**, выберите свой iPhone вместо симулятора.
2. При первом подключении Xcode подготавливает устройство («Preparing iPhone…», «Copying shared cache»). Это может занять несколько минут, дождитесь окончания.
3. Нажмите **▶ Run** (⌘R). Xcode соберёт приложение и установит его на iPhone.

### 8. Разрешите запуск приложения
При первом запуске iOS сообщит «Ненадёжный разработчик». Тогда:
**Настройки → Основные → VPN и управление устройством → «Приложение разработчика» → ваш Apple ID → Доверять «…» → Доверять.**
Запустите StreetLog с домашнего экрана или снова нажмите Run в Xcode.

### Важно знать
- **Подпись с бесплатным Apple ID действует 7 дней.** Потом приложение перестанет открываться. Чтобы продлить, подключите iPhone и снова нажмите Run в Xcode. Данные сохранятся, если не удалять приложение и не менять Bundle Identifier.
- С бесплатным аккаунтом одновременно можно установить до 3 своих приложений.
- С платной подпиской Apple Developer Program (99 $ в год) сертификат действует год.
- **Запуск без кабеля:** после первой установки откройте **Window → Devices and Simulators**, выберите iPhone и отметьте **Connect via network**. Mac и iPhone должны быть в одной Wi-Fi сети.
- Посмотреть приложение без телефона можно в симуляторе: выберите, например, «iPhone 16» и нажмите Run.

### Если что-то не получилось
| Сообщение | Что делать |
|---|---|
| `Failed to register bundle identifier` / `No profiles for …` | Смените Bundle Identifier на уникальный (шаг 4). |
| `Developer Mode disabled` | Включите режим разработчика (шаг 6). |
| `Untrusted Developer` / «Ненадёжный разработчик» | Доверьте сертификат (шаг 8). |
| `…is in a future Xcode project file format` | У вас Xcode 15. Обновите Xcode или выполните `brew install xcodegen && xcodegen generate` в папке проекта. |
| `iOS xx is not supported by this version of Xcode` | Обновите Xcode до последней версии. |
| iPhone не виден в списке устройств | Переподключите кабель, разблокируйте телефон, подтвердите «Доверять», перезапустите Xcode. |
| Приложение перестало открываться через неделю | Истекла 7-дневная подпись: подключите iPhone и нажмите Run. |
